### 📓 Jupyter Notebook Tutorial

**Best for:** Developers who learn by doing

An interactive 8-chapter notebook covering all framework features:

1. **Hello LegendStack** - Your first agent
2. **Understanding the Graph** - LangGraph workflows
3. **Safety Guardrails** - PII & moderation
4. **RAG Deep Dive** - Vector search
5. **Graph-RAG** - Knowledge relationships
6. **Memory & Entities** - Persistence
7. **Self-Correction** - Quality loops
8. **Build Your Agent** - Custom nodes

```bash
# Launch Jupyter and open the tutorial
jupyter notebook notebooks/tutorial.ipynb
```

**Estimated time:** 90 minutes

---

### 🖥️ Interactive Streamlit App

**Best for:** Visual learners who prefer guided experiences

A step-by-step walkthrough with live agent interaction:

- Real-time chat with the demo agent
- Toggle features on/off to see effects
- Code snippets with explanations
- Progress tracking

```bash
# Launch the tutorial app
streamlit run studio/tutorial_app.py
```

**Estimated time:** 30 minutes
